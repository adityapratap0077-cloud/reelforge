# ReelForge

Cinematic AI promo reels for local businesses. $40, delivered in 48 hours.

**Live site:** https://reelforge-opal.vercel.app

## What it is

ReelForge is a landing page + service site for an AI-generated promo-video offer aimed at
local businesses (cafés, gyms, boutiques, salons, restaurants). The page includes:

- Hero with AI-generated video background
- Three AI-generated sample reels (café, gym, boutique)
- How-it-works section, pricing ($40 single / $99 3-pack), FAQ, and Instagram-DM order flow

## Tech

Single static `index.html` with Tailwind CDN — no build step. Deploys straight to Vercel.

## Media

All sample videos and imagery were generated with AI; no camera shoots involved.
